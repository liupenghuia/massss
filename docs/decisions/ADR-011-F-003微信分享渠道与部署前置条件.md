# ADR-011 F-003 微信分享渠道与部署前置条件

Status: Accepted
Date: 2026-08-19
Feature: F-003（关联全局前台，见 ADR-001）
Supersedes: -

## Context

`/conflicts F-003` 问题 16、17：前台链接的主要传播路径是什么、前台域名的备案状态如何。
reviewer-miniapp 在 F-003 评审中指出，即便项目已确认不做微信小程序（ADR-001），
前台链接大概率会经由微信分享传播，绕不开微信生态对 H5 链接的一系列限制
（PDF 内置浏览器预览、CDN 域名安全策略、分享卡片信息等）。

## Decision

- 前台链接的主要传播路径**以微信内分享（群聊/好友）为主**，同时也支持复制纯 URL
  粘贴到其他平台使用。
- 前台域名**目前尚未完成 ICP 备案**，当前在本地环境运行，用户正准备购买云服务。
  正式对外上线前必须完成域名备案、并确认域名不在微信域名安全黑名单内，这是部署阶段
  的前置条件，本 ADR 只记录现状，不代表已经满足上线条件。

## Consequences

+ 明确了微信分享是主要场景，评估报告"新标签页打开"（ADR-010）、图片/报告公开直链
  （ADR-009）等决策需要在这个前提下被检验，目前的方案对微信场景是可用但非最优的
  （X5 内核对新标签页打开 PDF 的处理可能触发下载而非预览，这是可接受的降级，不是失败）。
+ 同时支持纯 URL 分享，意味着前台不能假设访问者一定来自微信环境，不能做微信专属的
  强依赖（与 ADR-001"不做小程序"的方向一致）。
- 域名未备案是一个已知的、明确的上线阻塞项，不在本次开发范围内解决，但必须在正式
  对外发布前完成，需要用户在采购云服务时一并规划备案周期（国内备案通常需要数个工作日
  到数周不等）。
- 分享卡片（Open Graph meta 信息）、CDN 域名是否命中微信安全策略，本次决策未覆盖，
  仍是遗留风险，建议域名确定后专门检查一次。
