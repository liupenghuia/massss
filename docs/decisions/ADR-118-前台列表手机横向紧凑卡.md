# ADR-118 前台列表手机横向紧凑卡

Status: Accepted
Date: 2026-08-24
Feature: F-002
Supersedes: ADR-117（仅「手机上整宽 4:3 竖卡」的排版密度）；封面仍锁 4:3、信息槽不变

## Context

ADR-117 把封面锁在 4:3，避免图片撑破卡片。手机竖屏若仍用整宽竖卡，375 宽封面约 280px 高，一屏几乎只能看一辆，扫列表成本高。原则是前台移动优先、适配只改密度不改信息架构。

## Decision

1. **&lt;720px**：列表卡横向——左封面（宽 120px、仍 4:3、object-fit cover），右标题 / 参数行 / 价格。同一套信息槽，不删字段。
2. **≥720px**：两列竖卡（ADR-117），封面仍整宽 4:3。
3. 管理后台卡片网格不跟这套走（后台桌面优先，仍用竖卡）。

## Consequences

+ 手机一屏能扫多辆，封面和价格同时在视口内。  
+ 信息不另做一套架构。  

- 手机封面更小，图细节不如竖卡；符合列表扫读，细节进详情。
