# ADR-014 F-004 前台价格展示规则

Status: Accepted
Date: 2026-08-19
Feature: F-004, F-002
Supersedes: -

## Context

`/conflicts F-004` 问题 13、14：前台价格变动记录的展示范围、展示逻辑的决策权归属。

## Decision

- 前台展示的价格变动记录限制为最近 20 条，超出部分分页/加载更多，不做全量展示。
- 展示逻辑的决策权归 F-004：由 F-004 的接口直接给出完整的展示数据（含数值格式化、
  "面谈"的统一文案"面议"），F-002（前台）只做渲染，不做二次判断（呼应"前端是哑终端"）。

## Consequences

+ 限制展示条数避免了前台一次性拉取全部历史拖慢首屏，尤其在移动端优先的取向下。
+ F-002 不需要理解价格数据的业务含义，只需渲染 F-004 给的现成数据，降低前端复杂度。
- 展示完整降价历史可能存在运营策略上的顾虑（例如议价心理），本决策未对此做特别处理，
  用户如后续认为需要收紧（如隐藏具体金额趋势），需要另行提出并走 RFC 调整。
