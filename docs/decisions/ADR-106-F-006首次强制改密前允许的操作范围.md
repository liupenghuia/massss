# ADR-106 F-006 首次强制改密前允许的操作范围

Status: Accepted
Date: 2026-08-21
Feature: F-006
Supersedes: -

## Context
第二轮评审（qa 视角）提出：首次登录（含密码重置后）强制改密完成前，是否允许登出、
切换账号、查看自己的只读信息等"改密页以外"的路径，spec 只说了"改密前无法使用其他功能"，
未列出登出这类账号自身操作是否算"其他功能"。

## Decision
`mustChangePassword=true` 期间，仅放行两类接口：修改密码本身、登出。
其余全部 `/admin/*` 接口（含查看自己账号只读信息、任何业务操作）一律返回 `MUST_CHANGE_PASSWORD`（403），
与现有 spec 描述一致，不新增例外。管理后台前端在改密页做路由守卫拦截其余页面跳转。

## Consequences
+ 范围最小、实现最简单，与现有 spec"改密前无法使用其他功能"的表述完全一致，不引入新分支逻辑。
- 用户在改密前无法登出去看其他信息再回来，只能改密或退出登录，交互上稍显生硬，
  但符合"强制改密"这一安全要求的本意。
