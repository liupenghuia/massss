# ADR-075 F-004 创建车辆带初始价格的事务边界

Status: Accepted
Date: 2026-08-21
Feature: F-004
Supersedes: -

## Context
spec.md 已确认"创建车辆可带初始价格"（ADR-015），但车辆行与首条价格记录之间的
事务边界未定义：是否要求二者在同一数据库事务内提交，失败时整体回滚。
domain/qa 视角均指出这可能产生"车辆已建但价格记录缺失"的孤儿状态，属于实现层面的
一致性问题，按默认协议选更小/更安全的一档直接裁决。

## Decision
创建车辆时若同时提供初始价格，车辆行写入与该首条价格记录写入包在同一个数据库事务内，
任一步失败则整体回滚，不会出现"车辆已创建但价格记录缺失"或反之的中间态。

## Consequences
+ 消除车辆与价格记录之间的一致性缺口，不需要额外的补偿/对账机制。
- 创建车辆接口的失败路径需要覆盖到价格写入失败的分支，错误信息需要能定位到具体是
  车辆字段问题还是价格字段问题，接口实现需要对应处理，不能简单地整体报"创建失败"。
