# ADR-017 F-004 前台展示与渠道归属修正

Status: Accepted
Date: 2026-08-19
Feature: F-004, F-002
Supersedes: ADR-014

## Context

`/conflicts F-004` 问题 13、14、22。ADR-014 已定「前台只展示最近 20 条」且由 F-004 给出
「面议」等展示文案。用户确认的本包将展示条数、分页、文案推迟到 F-002，F-004 只返回
类型与金额；微信内打开链接也不属于 F-004。本文件整份取代 ADR-014。

## Decision

- F-004 公开与管理读取接口对价格只给出结构化数据：类型（具体数值 / 面谈）+ 金额（面谈时为空）。
  不在 F-004 内规定「面议 / 电话咨询」文案、排序样式、默认条数。
- 前台展示几条、是否分页、是否全量、是否有议价顾虑，**推迟到 F-002** 评审时裁决；不阻塞 F-004。
- F-004 契约可为列表预留分页参数，但默认策略不在本 feature 定死。
- 通过微信（公众号、好友/群转发）打开车辆页 **不属于 F-004**，按 ADR-001 由 Web 链接覆盖，
  具体页面与分享信息归 F-002。

## Consequences

+ F-004 契约不夹带展示文案，避免 F-002 brief 仍空时把前台决策写死。
+ 渠道问题不再堵价格记录的定稿。
- ADR-014 的「最近 20 条」和统一「面议」文案作废，F-002 未定时前台实现没有展示默认值，
  联调 F-002 前需要先裁这两条。
- 若 F-002 后来要 F-004 下发文案，需走 RFC 改契约。
