# ADR-076 F-004 操作人字段展示口径

Status: Accepted
Date: 2026-08-21
Feature: F-004
Supersedes: -

## Context
ADR-016 已确认价格记录带"操作人"字段、本期用登录账号识别，但价格记录列表展示时
用登录账号名还是关联后台账号昵称未定。admin 视角提出这个问题，纯属展示口径分歧，
不涉及零容忍项或状态机/权限，按默认协议选更小范围的一档：不引入对昵称字段的依赖。

## Decision
价格记录列表展示的"操作人"字段直接显示登录账号名（loginName），不关联查询昵称。

## Consequences
+ 不需要额外的账号昵称字段或跨表关联查询，实现最简单，也不受 F-006 账号资料完善度影响。
- 登录账号名如果本身不够可读（如纯字母数字），列表展示的可读性打折扣；
  若未来账号体系补充昵称字段，可另开小改把这里换成昵称展示，不阻塞本期。
