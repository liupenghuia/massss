# ADR-110 F-001 能源类型联动维持服务端强校验

Status: Accepted
Date: 2026-08-21
Feature: F-001
Supersedes: ADR-038（部分：第1条"能源类型字段联动"）

## Context
ADR-038 第1条裁决"能源类型联动本期仅前端展示/隐藏，服务端不做强校验"，
但实现阶段核查发现 `server/src/lib/validation.ts` 早已实现了服务端强校验
（`INAPPLICABLE_TO_ENERGY_TYPE`，对应字段 `displacementL`/`energyConsumption`/`batteryKwh`），
并有测试覆盖。ADR-038 裁决时未核实现状，属于评审阶段的信息遗漏，非故意变更。

## Decision
维持现状：服务端继续对能源类型与排量/电耗/电池度数的组合做强校验，
不适用的字段传非 null 值时返回 `VALIDATION_ERROR`（`INAPPLICABLE_TO_ENERGY_TYPE`）。
前端仍按能源类型展示/隐藏对应输入项（不变）。本决定作废 ADR-038 第1条，其余条款不受影响。

## Consequences
+ 不需要改动/削弱现有已实现且有测试覆盖的校验逻辑，避免代码回退式改动引入风险。
+ 数据质量优于"仅前端拦"的方案，脏数据风险更低。
- ADR-038 与本 ADR 并存时，读者需要知道第1条已被本 ADR 取代，其余条款仍以 ADR-038 为准，
  spec.md 正文需要同步更新引用，避免两份文档表述矛盾。
