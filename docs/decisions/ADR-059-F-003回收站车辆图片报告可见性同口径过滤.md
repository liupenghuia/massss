# ADR-059 F-003 回收站车辆图片/报告可见性同口径过滤

Status: Accepted
Date: 2026-08-21
Feature: F-003
Supersedes: -

## Context
F-003 v1.2 边界与限制里遗留一条未裁决问题：已删除（回收站中，`trashedAt` 不为空）车辆的
图片/报告，`/public/*` 接口是否需要与"已下架"车辆同一口径过滤。该问题直接关系
docs/principles.md 零容忍项"已删除车辆仍在前端可见"，未按默认协议处理，留待用户明示。
用户已明确裁决。

## Decision
回收站中（`trashedAt` 不为空，含未彻底清除）车辆的图片/报告，在 `/public/*` 接口一律不可见，
与"已下架"车辆同一口径过滤：车辆本身走 F-005 的 `requirePublishedVehicle` 判断
（非 published 状态一律 404），挂在该车辆下的图片/报告接口同样先做这次判断，
车不可见时图片/报告接口也一律 404，不单独区分"图片本身是否存在"。

## Consequences
+ 与零容忍项"已删除车辆仍在前端可见"完全对齐，回收站车辆的图片/报告不会通过直链或
  列表接口在前台残留可见，消除潜在的信息泄露/错配风险。
- 图片/报告接口需要额外一次车辆状态判断（复用 F-005 已有的 `requirePublishedVehicle`
  或等价逻辑），不能只判断图片/报告记录本身是否存在。
