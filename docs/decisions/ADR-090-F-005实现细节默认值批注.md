# ADR-090 F-005 实现细节默认值批注（第二轮评审收尾）

Status: Accepted
Date: 2026-08-21
Feature: F-005
Supersedes: -

## Context
第二轮评审（qa/admin 视角）提出三项非零容忍的实现细节，均未在 principles.md/已有 ADR 中写明。
按 principles.md 默认协议，选择范围更小、本期能上线的一档，批量记录。

## Decision
1. **剩余保留天数取整规则**：服务端按向下取整计算剩余天数，不足一天按 0 天展示
   （即当天将被清除时展示"剩余 0 天"），偏保守，避免管理员误判还有余量。
2. **重复删除幂等提示**：管理后台在重复删除已在回收站中的车辆时，
   追加一条非阻断提示"该车辆已在回收站中，保留期不变"，帮助管理员理解为何倒计时未刷新；
   不改变接口幂等成功的行为本身。
3. **回收站列表关键字搜索字段范围**：与在管列表（F-001 已定义的搜索字段）保持一致，
   不额外扩大或缩小搜索范围。

## Consequences
+ 三项均是低成本、不阻塞开工的收敛决策，避免实现时各自臆测。
- 若未来产品侧希望"剩余天数"改为向上取整（更乐观展示），或搜索范围需要扩展（如支持按删除时间搜索），
  需要另外提出并走小改 + 新 ADR 流程。
