# ADR-019 F-002 公开接口读模型与缓存规则

Status: Accepted
Date: 2026-08-19
Feature: F-002, F-001, F-003, F-004
Related: ADR-005（无缓存延迟）、ADR-007（可增长规模）、ADR-009（直链不失效）

## Context

`/conflicts F-002` 冲突项 C-2、C-3、C-4、C-7、C-8，以及需用户裁决问题 5、6、7、8、9、10、17、18、19。
公开列表当前契约不含图片与价格，若前台逐条补打接口会产生 N+1 与竞态；同时 CDN 缓存与
ADR-005「下架实时生效」存在直接冲突。本文件定稿公开读模型的形状与时效性。

## Decision

### 列表读模型（需 RFC 改契约）
- `GET /public/vehicles` **扩展为聚合读模型**，一次返回卡片所需全部数据：
  - F-001 公开 schema 的文本字段
  - **封面图缩略图 URL**（由服务端字段保证，前台不得自行拼接 CDN 参数）
  - **当前价格的类型 + 金额**（当前价 = 最新一条价格记录的变动后值，服务端计算）
- 前台**禁止**对列表每条再打 `images` / `price` 接口，杜绝 N+1 与「列表在、价格 404」竞态。
- 字段只增不改语义。该变更**必须先走 RFC 修改 `contracts/openapi.yaml`**，实现期不得私自加字段。

### 排序与分页
- 公开列表排序固定为服务端 **`id` 降序**，前台**禁止任何本地重排、筛选、排序切换**。
- 列表**必须分页**，默认 `pageSize = 20`，按 ADR-007 可增长规模设计，禁止一次拉全量。
- 本期不做置顶、推荐位、手动排序（属新运营能力，需另开 feature）。

### 不可见语义
- 非 `published`（草稿 / 已下架 / 未来的回收站态）与不存在的 id，公开接口**一律** `404 VEHICLE_NOT_FOUND`，
  禁止 403、禁止任何可枚举状态的差异响应。
- 页面统一渲染「找不到该车辆」，**不区分**下架 / 回收 / 乱猜 id，不出现「已下架」等前台伪状态。
- 浏览中途车辆被下架：列表已发出的数据保持原样，用户点入详情时按上述统一 404 处理。

### 缓存
- 公开 GET 接口**禁止 CDN / HTTP 缓存，TTL = 0**，严格遵守 ADR-005。
- 下架、改价后，下一次 GET 立即以服务端最新数据为准，可见延迟为 0。
- 验收口径：下架后立刻请求公开接口即须 404。

### 对象存储直链
- 公开图片与报告使用**永久公开直链，不开 Referer 防盗链、不使用过期签名**
  （防盗链会导致微信内图片加载不可控地失败）。
- 承认并接受 ADR-009 的既有事实：车辆下架后页面 404，但旧文件直链仍返回 200。
  两者是不同层面的事，联调用例中**均判通过**。

### 限流
- 公开接口加**基础 IP 级速率限制**，防止恶意批量拓库。
- 书面接受：已上架车辆本就是对外公开信息，车辆 id 可被按序遍历是可接受的。

## Consequences

+ 首屏一次请求拿全卡片数据，移动端体验与失败面都最优。
+ 不可见语义单一，无状态泄漏，QA 断言简单。
+ 零缓存使「下架立即不可见」可测且无歧义。
- 列表契约扩展**阻塞在 RFC 上**：RFC 通过并改完 `contracts/` 之前，F-002 实现不能开工。
- 禁用 CDN 缓存放弃了加速与成本优化，当前一百台规模内无压力，规模增长后可能需重新评估
  （届时须新开 ADR 覆盖本条，不得在实现期私自加缓存）。
- 不防盗链意味着图片可被同行直接引用，属已知且接受的代价。
