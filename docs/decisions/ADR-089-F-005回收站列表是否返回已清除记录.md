# ADR-089 F-005 回收站列表是否返回已清除记录

Status: Accepted
Date: 2026-08-21
Feature: F-005
Supersedes: -

## Context
第二轮评审（admin 视角两次提出）：回收站分页列表接口是否会一并返回 `purged=true`
的已清除记录，还是已清除记录只能通过按 id 检索查看，spec.md 虽然分别描述了"回收站列表"
与"按已清除车辆 id 检索"两种能力，但未明确二者对 `purged=true` 记录的处理是否互斥。

## Decision
回收站分页列表接口（`GET .../recycle-bin` 系列）只返回 `trashedAt` 不为空
且 `purged=false` 的"进行中"回收站记录；`purged=true` 的已清除记录不出现在分页列表结果中，
只能通过既有的"按已清除车辆 id 检索"能力单独查看其主记录信息与价格历史。
这是既有两种能力的行为边界澄清，不引入新接口，不改变已 Accepted 的
`docs/rfc/2026-08-19-F-005-回收站接口.md` 契约结构。

## Consequences
+ 回收站列表页面语义清晰："回收站"只展示尚在保留期内、可恢复的车辆，已彻底清除的不再露出，
  避免列表随时间无限增长、管理员误以为已清除车辆还能恢复。
- 需要管理员已知车辆 id 才能查已清除记录，本期不提供已清除记录的独立可搜索列表，
  如未来有审计/追溯需求需要该列表，需另开 RFC。
