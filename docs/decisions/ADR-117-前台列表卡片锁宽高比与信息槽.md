# ADR-117 前台列表卡片锁宽高比与信息槽

Status: Accepted
Date: 2026-08-24
Feature: F-002
Supersedes: -

## Context

前台 `VehicleCard` 把 `vehicle-card-cover` 直接打在 `<img>` 上。封面框的固定高度被
`img { height: 100% }` 盖掉，百分比相对高度为 auto 的父级，图片按自身像素撑开卡片。
竖图/截图会把标题和价格顶出第一屏，看起来像「有的卡只有图、卡片大小不一」。

## Decision

1. 封面必须是**框**：`aspect-ratio: 4 / 3`，`overflow: hidden`。图在框内 `object-fit: cover`，
   不得按图片固有高度撑开卡片。`SmartImage` 根节点是框，`<img>` 铺满框。
2. 卡片信息槽固定：封面 → 车型标题（一行截断）→ 年款/里程/颜色/能源一行 → 价格。无封面用字标占位；
   缺字段用「—」，**不得省略整块正文**。
3. 同一行网格里卡片等高（stretch + 正文区 flex）。这是列表验收项，不是可带上线的裁切瑕疵。

## Consequences

+ 不同比例的实拍/截图不会把列表撑乱。  
+ 每张卡都能看到车型和价格。  

- 非 4:3 的图会被裁切边缘；符合封面用途。  
- 详情页规格表空值隐藏（既有规则）与列表卡「槽位始终在」不同，实现时不要混用。
