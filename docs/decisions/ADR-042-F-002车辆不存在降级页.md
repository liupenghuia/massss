# ADR-042 F-002 车辆不存在/已下架降级页

Status: Accepted
Date: 2026-08-21
Feature: F-002
Supersedes: -

## Context
ADR-088（F-005）指出车辆进回收站/被清除/下架/草稿后，前台详情页服务端返回 404，
但前台展示层此前没有为这个 404 设计专门的降级 UI，容易表现为浏览器默认空白/错误页，
在微信内置浏览器下体验尤其差。ADR-088 已把这个待办正式移交给 F-002 认领。

## Decision
前台详情页请求返回 404 时，展示一个统一的"车辆不存在或已下架"降级页面，而非空白页或
浏览器默认错误页。按 principles.md 默认协议选更小范围：页面只包含简短文案说明
（"该车辆不存在或已下架，可能已被下架或删除"）+ 一个返回列表页的入口，不做"猜你喜欢/
相关车辆推荐"等扩展功能。列表页同理，接口返回空数据时展示统一空状态提示，不视为错误。

## Consequences
+ 补齐 ADR-088 移交的降级 UI 缺口，避免访客（尤其微信内置浏览器打开旧分享链接时）
  看到空白页或浏览器原生错误页，体验闭环。
- 需要前端识别 404 响应并渲染专门的降级组件，而非把所有非 200 响应统一交给全局错误边界处理。
