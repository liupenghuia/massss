# ADR-109 F-006 超级管理员禁止自我降级

Status: Accepted
Date: 2026-08-21
Feature: F-006
Supersedes: -

## Context
F-006 权限矩阵已裁决"不能停用自己"与"不能把最后一个启用超管降级"，但未覆盖
"超级管理员能否把自己降级为 admin"（在自己不是最后一个启用超管的前提下）这一情形。
该问题涉及权限模型设计，属于需要用户明示的红线，第二轮评审未替用户拍板。
用户已明确裁决。

## Decision
超级管理员不能把自己降级为 admin，无论自己是否是最后一个启用超管，一律禁止自我降级
（与"不能停用自己"同一防误操作逻辑：本人对自己的角色/启用状态没有自毁能力，
必须由另一个超级管理员操作）。修改角色接口对"目标账号 = 调用者自己"的请求一律拒绝，
不区分升级还是降级方向。

## Consequences
+ 与"不能停用自己"保持一致的防误操作原则，避免超级管理员误操作把自己降权后
  又要靠别的超管救场，降低运维风险。
- 超级管理员如果确实想主动放弃超管权限，必须请另一个超级管理员代为操作，
  单人超管账号（仅一个启用超管时）无法自我降级也无法被他人降级（受"最后一个超管"保护），
  这种情况下角色只能靠新增另一个超管后再降级，属于已知的操作路径限制。
