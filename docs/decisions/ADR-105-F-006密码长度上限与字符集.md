# ADR-105 F-006 密码长度上限与字符集

Status: Accepted
Date: 2026-08-21
Feature: F-006
Supersedes: -

## Context
现有 spec 只定义了密码下限（最少 8 位含字母数字），上限长度与允许字符集未定义，
第二轮评审（qa 视角）提出。

## Decision
密码长度上限 72 字符（与 argon2id/bcrypt 等哈希算法的常见安全长度上限对齐，超出部分对哈希强度
无实际增益）；字符集不做额外限制，允许任意可打印 UTF-8 字符（含常见符号、非 ASCII 字符），
仅拒绝控制字符（如换行、制表符等不可见控制码）。超出长度上限或包含控制字符返回 VALIDATION_ERROR。

## Consequences
+ 给出明确可实现的边界值，避免实现时随意拍板，也避免管理员设置过长密码导致哈希/存储异常。
- 不做字符集白名单意味着允许 emoji 等特殊字符，实现时需要确保输入框、数据库列、
  日志脱敏等环节统一按 UTF-8 处理，不做额外的字符集校验分支。
