# ADR-088 F-005 前台 404 降级 UI 归属

Status: Accepted
Date: 2026-08-21
Feature: F-005
Supersedes: -

## Context
第二轮评审（miniapp 视角）指出：车辆被删除/清除后，前台详情页返回 404，微信内置浏览器下
需要有清晰的降级 UI（而非白屏），但这属于前台展示层的通用能力，不是 F-005（回收站，
管理后台内部功能）能直接负责的范围。miniapp 明确表示这不归自己认领，无人回应归属。

## Decision
前台 404 详情页的降级 UI（含微信内置浏览器下的展示）不属于 F-005 交付范围，
推迟到 F-002（前台车辆展示）负责设计通用的"车辆不存在/已下架"降级页面，
F-005 只负责保证服务端在车辆进回收站/被清除后对公开接口返回明确的 404
（已在 spec.md 中定义），不阻塞 F-005 本身的开工。

## Consequences
+ 明确职责边界，F-005 不需要为一个前端展示细节等待跨 feature 协调。
- F-002 若未同步跟进这条待办，短期内 404 页面可能只是浏览器默认的空白/错误页，
  不算 F-005 的缺陷，但用户体验上有缺口，需要在 F-002 评审时提醒认领
  （F-002 conflicts.md 目前未包含此项，建议下次处理 F-002 裁决时一并纳入）。
