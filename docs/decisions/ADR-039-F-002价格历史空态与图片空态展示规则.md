# ADR-039 F-002 价格历史空态与图片空态展示规则

Status: Accepted
Date: 2026-08-21
Feature: F-002
Supersedes: -

## Context
第二轮评审（qa 视角）提出两处未覆盖的空态：
1. 新车尚无价格变动记录时，价格历史区展示什么文案未定义。
2. 图片数量为 0（边界防御场景，正常流程下 F-001 发布前置条件已保证 ≥4 张，
   但历史脏数据或未来规则变化可能出现）时前台如何渲染未定义。

按 principles.md 默认协议，均非零容忍/状态机/权限类问题，选范围更小、本期能上线的一档。

## Decision
1. 价格历史为空时，价格历史区展示文案「暂无价格变动记录」，不隐藏整个区块（价格类型本身非空值字段，
   与展示规则表的"空值隐藏整行"不是同一场景，此处是"整个列表为空"而非"某个字段为空"）。
2. 图片数量为 0 时，图片区块整体不渲染（不展示空框、占位图或"暂无图片"文案），
   与评估报告"无报告：整块隐藏"的处理方式保持一致。

## Consequences
+ 两处空态都有确定的处理规则，可直接写成自动化断言，不再是隐含假设。
- 图片区整体隐藏意味着如果确实是数据异常（不应为 0 张图的车辆变成 0 张），
  前台不会给出任何视觉提示，问题只能靠后台侧发现，不属于前台职责范围。
