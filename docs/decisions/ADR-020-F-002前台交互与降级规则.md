# ADR-020 F-002 前台交互与降级规则

Status: Accepted
Date: 2026-08-19
Feature: F-002
Related: ADR-010（评估报告新标签打开原文件）

## Context

`/conflicts F-002` 冲突项 C-5、C-6、C-11，以及需用户裁决问题 12、13、14、15、22。
ADR-010 规定评估报告「新标签打开」，但微信 iOS WebView 常拦截或内嵌预览，该行为不可控；
同时分享卡片、后台预览入口、错误态文案均无人认领。本文件定稿这批交互与降级。

## Decision

### 分享
- 本包只做**服务端渲染的静态 OG meta 头**：标题 = 品牌车型，描述 = 关键参数，封面 = 首图。
- **不调用微信 JS-SDK、不绑定公众号、不申请 JS 安全域名**，不做微信自定义分享卡片。
- 微信可能不读取 OG 头，属已知限制；其他渠道（浏览器、社交平台）可正常生成预览。
- 分享的就是普通 Web URL，不造「分享专用价」等衍生数据。

### 后台前台入口
- 管理后台车辆详情页对**已上架**车辆展示**可复制的前台 URL**。
- 未上架车辆该入口**置灰并注明原因**，不提供任何形式的未发布预览。
- **不做**独立 admin 预览模型，禁止把 admin cookie 复用到公开页冒充访客。

### 评估报告
- 无评估报告时**整个报告区块不渲染**（与 ADR-018 空值隐藏行策略一致），不展示置灰入口。
- 多份报告按服务端返回顺序列出**文件名 + 上传时间**；不展示上传人，不设「主报告」概念。
- 打开策略与降级（放宽 ADR-010 的字面要求）：
  1. 优先新标签打开原文件 URL
  2. 被拦截则当前 WebView 打开
  3. 仍失败则提示「请在浏览器中打开」
  以上三种结果**均判验收通过**。禁止为保存文件申请任何文件系统权限。

### 图片
- 点击图片打开**灯箱**查看（手机端支持左右滑动切换），不跳出详情页。
- 图片说明为空时**不渲染说明区**，不占位。
- 图片顺序严格按公开接口返回顺序，前台不得重排。

### 错误态与空态（属本 feature 验收范围）
- 5xx / 超时 → 「加载失败，请重试」+ 重试按钮（对 GET 可安全重试）
- 详情 404 → 「找不到该车辆」（见 ADR-019 统一语义）
- 空列表（一台未上架）→ 「暂无在售车辆」，**允许空态上线**
- 禁止用部分成功的数据拼出「车还在、价没有」的半残页面。

## Consequences

+ 交互与文案全部有唯一定稿值，QA 可直接写用例。
+ 明确放弃微信专属能力，避免本包滑向「半个用户运营系统」。
+ 报告打开的三态降级把不可控的端差异排除在验收之外。
- 微信内分享出去可能只有裸链接样式，运营需知晓；若将来要微信卡片必须另开 feature。
- 放宽 ADR-010「必须新标签」的字面要求，本 ADR 在 F-002 范围内优先。
- 无未发布预览意味着已上架编辑立即对客生效，运营改错只能先下架再改。
