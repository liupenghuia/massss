# ADR-034 F-001 车况描述与车辆描述字段合一

Status: Accepted
Date: 2026-08-21
Feature: F-001
Supersedes: -

## Context
第二轮评审（domain 视角）发现术语歧义：F-001 spec 的必填字段"车况描述"与
docs/product/overview.md 术语表中的"车辆描述"可能指同一字段，也可能是两个字段，
spec 未明确区分，已列入 conflicts.md 待裁决。

同时需要澄清"车况描述/车辆描述"与 F-003 中挂在单张图片上的"图片说明"（caption）
不是同一个东西，避免后续实现把两者混用。

## Decision
"车况描述"与 overview.md 中的"车辆描述"是同一个字段，挂在车辆整体上，
一辆车只有一份。它与 F-003 中每张图片各自的"图片说明"是两个独立字段，互不影响、互不同步。

## Consequences
+ 消除字段歧义，避免实现时建出两个重复字段或误把图片说明当车辆描述使用。
- 无实质代价，纯澄清性决策。
