# ADR-018 F-002 价格与字段展示规则

Status: Accepted
Date: 2026-08-19
Feature: F-002
Related: ADR-017（本文件补齐 ADR-017 推迟给 F-002 的展示决策）

## Context

`/conflicts F-002` 冲突项 C-1、C-9，以及需用户裁决问题 1、2、3、4、16。
ADR-017 已将「面谈文案、展示条数、金额格式」推迟到 F-002 定稿，且 F-004 公开接口
只返回价格类型 + 金额。本文件给出这批展示规则的唯一定稿值，作为实现与测试夹具。

## Decision

### 面谈文案
- F-004 公开契约**不变**：仍只给结构化的类型 + 金额，服务端不下发展示文案。
- 前台对价格类型做**唯一死映射**，面谈类型统一渲染为「面议」。该映射是常量表、无业务分支，
  不视为前端做业务判断。
- 管理后台展示同一词「面议」，两端用词一致。

### 金额格式
- 统一格式为「以万为单位、保留两位小数、后缀"万"」，例：`128000` → 「12.80 万」。
- 面谈类型金额为空时**只渲染「面议」，禁止显示 0、禁止显示「0.00 万」或空金额占位**。

### 价格变动记录
- 前台**全量展示**该车全部价格变动记录，排序为**新到旧**，不分页、不截断。
- 每条展示：价格类型 + 金额 + 变动日期。
- **禁止**在公开响应与页面出现操作人、操作账号、内部备注等任何内部字段。
- 后台可见条数与前台一致（均为全量），不设「后台更多、前台更少」的差异合同。

### 空值字段
- 本 feature 在 spec 中写死唯一空值映射表，前台按表执行，不自行判断：
  - `null` / 空字符串 → **隐藏整行**（该字段不渲染）
  - 数字 `0` 是有效值，照常展示（里程 0、过户 0 均正常显示）
- 无评估报告时隐藏整个报告区块（见 ADR-020）。
- 该映射表同时作为测试夹具，QA 按表断言。

## Consequences

+ F-004 公开契约无需变更，不必为文案走 RFC。
+ 文案、格式、条数全部有唯一定稿值，QA 可写断言。
+ 价格历史全量展示强化了「看得到降价轨迹」这一产品卖点。
- 前台持有一张类型→文案映射表，若将来新增价格类型必须同步更新该表，否则会渲染出空文案。
- 价格记录极多的车辆详情页会较长，当前一百台规模内可接受；若单车记录数失控需另开优化。
