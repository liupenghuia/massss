# ADR-107 F-006 登录锁定不支持手动解锁

Status: Accepted
Date: 2026-08-21
Feature: F-006
Supersedes: -

## Context
第二轮评审（qa 视角）提出：登录失败锁定（15 分钟）能否被超管手动解锁，还是只能等待自动解锁
或走停用/启用流程，未定义。

## Decision
本期不提供"手动解锁"功能。锁定账号只能等待 15 分钟自动解锁，或由超级管理员先停用再重新启用
该账号（重新启用会按 ADR-101 强制触发一次改密，等同重置状态）。

## Consequences
+ 不新增功能面，复用已有的停用/启用流程即可绕过锁定，范围最小。
- 15 分钟内如果情况紧急（如管理员本人误触发多次锁定），只能等待或走"停用再启用"这个稍显绕路的
  操作路径，没有专门的"立即解锁"按钮，属于可接受的本期限制。
