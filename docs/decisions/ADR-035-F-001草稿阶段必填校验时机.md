# ADR-035 F-001 草稿阶段必填校验时机

Status: Accepted
Date: 2026-08-21
Feature: F-001
Supersedes: -

## Context
第二轮评审（qa 视角）提出：车辆核心字段（品牌/车型/年份等）标记为"必填"，
但草稿保存时是否也强制这些字段非空未明确，影响能否写出确定性验收用例。

## Decision
草稿保存不强制校验必填字段是否非空，允许字段缺失时保存为草稿。
必填字段仅在发布动作（草稿→已上架、已下架→重新上架）时才强制校验，
与 ADR-003 的发布前置条件校验属于同一次校验动作。

## Consequences
+ 管理员可以先占位保存不完整的车辆信息，逐步补全，不被草稿阶段的校验打断录入流程。
- 草稿态可能长期存在字段缺失的"半成品"车辆，列表页展示这些字段时需要容忍空值渲染。
