# ADR-115 管理后台保存/发布操作区反馈

Status: Accepted
Date: 2026-08-24
Feature: F-001
Supersedes: -

## Context

车辆编辑页「保存并发布」「保存草稿」点完后，成功路径曾静默：按钮无进行态，结果写在页顶弱文案里，且保存成功后还要等列表 N+1 刷新才 setInfo。操作按钮在粘性侧栏，用户看不到页顶，体感是「点了没反应」。

## Decision

1. **保存草稿、保存并发布、下架**必须同时有：被点按钮的进行体文案（「保存中…」等）、操作区就地结果（成功用 `banner-ok`，失败用 `banner-warn`）。不得只改页顶横幅。
2. **成功文案在写接口返回后立刻给出**，不得等列表封面/价格兜底请求完成。列表刷新可后台进行。
3. 草稿成功：「草稿已保存」。已上架/已下架成功：「车辆信息已保存」。发布成功：「已保存并发布，前台现在可以看到这辆车」。下架成功：「已下架，前台不再展示」。
4. 不改变 PATCH/发布/下架的接口与校验时机。

## Consequences

+ 操作发生在哪、反馈就在哪，符合就近原则。  
+ 保存不再被列表 N+1 拖成「假死」。  

- 列表卡片可能比侧栏成功提示晚一小会儿更新封面/价，可带上线。
