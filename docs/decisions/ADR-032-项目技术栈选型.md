# ADR-032 项目技术栈选型

Status: Accepted
Date: 2026-08-19
Feature: 全项目

## Context

六个 feature 契约均已定稿（contracts/openapi.yaml），进入实现阶段前需要选定技术栈。
仓库此前无任何代码，principles.md 只约束了"Web，不做小程序"。用户裁决技术栈。

## Decision

- 后端：Node.js + TypeScript + Express
- 前端（前台 + 后台管理，同技术栈分开部署，对齐 ADR-028 不同域）：React + Vite + TypeScript
- 数据库：PostgreSQL
- 对象存储：阿里云 OSS

## Consequences

+ 后端与前端同为 TypeScript，可共享类型定义（如从 openapi.yaml 生成的类型）。
+ PostgreSQL 的行级锁/事务模型与契约里大量的乐观锁（version）、F-005 的恢复优先竞态需求契合。
+ 一百台规模下三者均无性能顾虑，优先保证开发效率。
- 需引入 openapi-typescript 或等价工具链维持契约与代码同步，否则契约与实现容易漂移。
