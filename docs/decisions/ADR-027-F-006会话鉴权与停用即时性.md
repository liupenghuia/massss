# ADR-027 F-006 会话、鉴权与停用即时性

Status: Accepted
Date: 2026-08-19
Feature: F-006

## Context

`/conflicts F-006` 冲突项 C-3，用户裁决问题 8-13、16。
「停用后立即不能再登录、不能再改数据」是 brief 的零容忍成功标准，其可实现性完全取决于
会话载体是否可服务端吊销。本文件定稿会话形态与鉴权响应规则。

## Decision

### 会话载体
- 会话**存服务端**（如 Redis / DB session store），客户端只持有不透明会话标识（cookie）。
- **禁止**把角色/权限塞进不可吊销的长期 JWT。
- 每次 `/admin/*` 请求都**实时校验**该账号当前是否已停用；停用后**下一次请求立即失败**，
  允许最多一次已经在服务端执行中的写请求跑完（不做强制中断进行中的数据库事务）。
- 账号被停用或修改密码时，**作废该账号的全部现有会话**（不限发起停用操作的这一台设备）。

### 会话策略
- 有效期 **8 小时，滑动过期**：每次成功请求刷新过期时间；8 小时无操作自动过期。
- 同一账号**允许多端 / 多标签页同时在线**，不做单设备互踢。

### 密码与登录锁定
- 密码最少 **8 位，需同时包含字母与数字**。
- 连续 **5 次登录失败锁定该账号 15 分钟**，锁定期内即使密码正确也拒绝登录。
- 登录名全局唯一，规则见 ADR-028。

### 鉴权响应
- **未登录**访问 `/admin/*`（登录接口本身除外）：`401`，前端跳转登录页。
- **已登录但角色不足**（如管理员访问超管专属接口）或**账号已停用**：`403`，
  前端展示「无权限」提示，不跳登录页（区别于会话过期）。
- 登录接口本身**匿名可访问**；除登录接口外的 `/admin/*` 路由**全部要求已登录**。
- 登录页 URL **不在** `/admin/*` 路由前缀下，允许未登录访问，避免与鉴权中间件互斥。
- 账号管理写接口（建号/停用/重置密码）**服务端二次校验超级管理员角色**，不能仅靠前端隐藏按钮。

## Consequences

+ 服务端会话使「停用立即生效」这一零容忍成功标准可实现、可测试。
+ 8 小时滑动过期在安全性与使用体验之间取得平衡，日常操作不会频繁掉线。
+ 401/403 分离让前端能区分「请登录」与「无权限」两种不同提示。
- 服务端会话存储引入额外的存储与运维成本（相对无状态 JWT），需要会话存储的可用性保障。
- 停用后最多一次进行中的写请求会跑完，理论上停用瞬间存在极短窗口的操作可能生效，
  属已知可接受的代价（不做强制中断事务）。
- 允许多端同时登录意味着无法从会话数量判断「账号是否被共享」，本期不做此类风控。
