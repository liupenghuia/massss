# ADR-103 F-006 登录锁定与 IP 限流同时触发优先级

Status: Accepted
Date: 2026-08-21
Feature: F-006
Supersedes: -

## Context
第二轮评审（qa 视角）提出：登录失败锁定（同账号连续 5 次失败锁 15 分钟）与登录接口的
IP 级限流同时触发时，返回哪个错误码、是否有优先级，未明确。

## Decision
IP 级限流是更粗粒度、更早介入的防线，检查顺序上先于账号级锁定：请求先过 IP 限流检查，
超限直接返回 `TOO_MANY_REQUESTS`（429），不再往下走到账号锁定判断；
只有通过限流检查后，才继续判断该账号是否被锁定（`ACCOUNT_LOCKED`，403）。

## Consequences
+ 与现有中间件分层顺序一致（限流通常在应用逻辑之前的网关/中间件层拦截），实现改动最小。
- 如果攻击者精确控制请求频率长期停留在限流阈值以下但仍在暴力破解某个账号，
  账号锁定机制仍会独立生效，两层防线互不替代，不构成安全弱化。
