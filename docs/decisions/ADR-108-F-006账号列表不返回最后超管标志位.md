# ADR-108 F-006 账号列表不返回"最后一个超管"标志位

Status: Accepted
Date: 2026-08-21
Feature: F-006
Supersedes: -

## Context
第二轮评审（admin 视角）提出：账号列表接口是否需要返回"当前是否为最后一个启用超管"的判断依据，
供前端做操作前置提示（如禁用停用按钮）。

## Decision
本期账号列表接口不新增该字段。前端不做操作前置判断，停用/降级最后一个启用超管时依赖服务端已有的
`LAST_SUPER_ADMIN` 错误码（409）兜底拦截，前端收到该错误码后展示对应提示文案。

## Consequences
+ 不新增接口字段和前端"是否最后一个超管"的判断逻辑，范围最小，复用已有错误码机制。
- 用户体验上是"点击后才知道不行"而非"按钮提前置灰"，多一次无效点击，
  如果后续觉得体验不佳，可以再补充该字段，不阻塞当前上线。
