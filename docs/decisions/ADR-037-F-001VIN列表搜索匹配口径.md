# ADR-037 F-001 VIN 列表搜索匹配口径

Status: Accepted
Date: 2026-08-21
Feature: F-001
Supersedes: -

## Context
第二轮评审（admin/api 视角）提出：管理后台车辆列表关键字搜索命中字段未定，
其中 VIN 因页面上只展示后六位，搜索时是按完整车架号匹配还是按展示的后六位匹配未明确，
影响索引设计。

## Decision
管理后台列表关键字搜索对 VIN 按展示的后六位匹配，不支持输入完整车架号搜索。

## Consequences
+ 搜索行为与页面展示口径一致，管理员照着看到的后六位搜索即可命中，不产生"看得到却搜不到"的困惑。
- 完整 VIN 前面部分不可搜索，如果未来需要按完整 VIN 精确查找需另外提供入口，本期不做。
