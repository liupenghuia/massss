# ADR-033 F-002 公开字段范围、运营话术与深链 URL

Status: Accepted
Date: 2026-08-19
Feature: F-002
Supersedes: -

## Context

F-002 open-questions #23、#24、#26 仍为 ⏳，阻塞文档一致性检查，并导致前台无法对齐验收中的直链与分享。
用户已全权授权处理剩余未决。公开接口契约已定稿（ADR-019 / ADR-029），本 ADR 只定产品边界与前台路由，不改 `contracts/`。

## Decision

### 公开字段（原问题 23）
访客必须看到的字段 **仅限于**：F-001 公开 schema + 列表聚合字段 `coverImageUrl` + `currentPrice`。
**不再增加**其它访客字段（所在城市、排放等）。若以后要加，必须新开 RFC 改契约。

### 运营话术（原问题 24）
本包 **不产出**「先下架再改」运营手册或话术。
行为仍以 ADR-019 为准：已上架车辆的编辑/改价对客立即生效。是否先下架由运营自行判断，产品不强制、文档不另写操作脚本。

### 深链 URL（原问题 8 / 26）
前台为 Web SPA，路由如下（相对前台站点 origin，不含管理后台 origin）：

| 页面 | URL | 说明 |
|---|---|---|
| 列表 | `/` | 筛选与分页进查询串 |
| 详情 | `/vehicles/{id}` | `{id}` 为车辆技术主键；非法或不存在由页面展示「找不到该车辆」 |

列表查询串（均为可选，与 `GET /public/vehicles` 对齐）：

- `page`：从 1 起；缺省为 1。`pageSize` **不进 URL**（固定 20，ADR-019）。
- `keyword`、`priceMin`、`priceMax`、`registrationYearMin`、`registrationYearMax`、`mileageKmMin`、`mileageKmMax`

规则：

- 刷新、分享、从后台复制的链接必须落到同一页同一筛选。
- 前台用 History API，禁止 hash 路由（`#/vehicles/1` 不算本 ADR 的深链）。
- 管理后台对已上架车辆复制的 URL = `{PUBLIC_WEB_ORIGIN}/vehicles/{id}`。未上架不提供可点击复制。
- `PUBLIC_WEB_ORIGIN` 由部署环境注入（管理后台构建变量 `VITE_PUBLIC_WEB_ORIGIN`）；本机缺省 `http://127.0.0.1:5173`。不得写进仓库密钥文件。

本 ADR **不改** OpenAPI 路径（公开接口仍是 `/public/vehicles`）。页面路径与 API 路径刻意分离。

## Consequences

+ 分享、刷新详情、验收「访问 `/vehicles/999999`」有唯一口径。
+ 公开字段不再开口，避免前台私自加展示列。
+ 不写运营话术，减少与「立即生效」行为互相打架的文档。
- 列表深链依赖查询串，运营口播时较长。
- 纯 SPA 的「查看源代码」看不到按车变化的 OG 头；OG 仍按 ADR-020 尽力提供（客户端写入 document），爬虫未跑 JS 时可能只有站点级默认头。本期接受该代价，不做独立 SSR 站点。
- 前后台不同 origin 时，复制链接依赖正确配置 `VITE_PUBLIC_WEB_ORIGIN`，配错会把客户指到后台域。
