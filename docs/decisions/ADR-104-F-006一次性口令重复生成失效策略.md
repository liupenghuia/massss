# ADR-104 F-006 一次性口令重复生成失效策略

Status: Accepted
Date: 2026-08-21
Feature: F-006
Supersedes: -

## Context
第二轮评审（qa 视角）提出：建号/重置密码操作超时（如网络超时导致管理员未收到口令）后再次调用，
是否会使前一次生成的口令立即失效，未明确。api 视角只答复"有审计日志可供核实"，未直接回答行为本身。

## Decision
每次调用建号/重置密码，立即使该账号此前所有未使用的一次性口令失效，只有最新一次生成的口令有效。

## Consequences
+ 避免同一账号同时存在多个"看似有效"的一次性口令，减少凭证混淆和潜在的凭证泄露窗口（安全默认值）。
- 如果管理员第一次调用其实已经把口令发给了新同事、只是自己没确认成功就又点了一次，
  会导致新同事拿到的口令失效，需要用新生成的那次重新交付，属于可接受的操作纪律成本。
