## 状态机

见 ADR-004。三态：草稿(draft) / 已上架(published) / 已下架(unpublished)。

- 草稿 → 已上架：发布（需满足 ADR-003 发布前置条件）
- 已上架 → 已下架：下架
- 已下架 → 已上架：重新上架（同样需满足发布前置条件）
- 不支持"已下架 → 草稿"
- 编辑操作与状态转换解耦，编辑不改变当前状态
- 非法转换（如对草稿执行"重新上架"）返回错误；对已处于目标状态的重复调用视为幂等，返回成功

## 核心字段

见 ADR-002。

**必填**：品牌、车型、上牌年份、里程、颜色、车况描述、能源类型（汽油/纯电/插电混动/增程式）、过户次数（手数）

- "车况描述"与 docs/product/overview.md 术语表中的"车辆描述"是同一字段（ADR-034），
  与 F-003 中每张图片各自的"图片说明"是两个独立字段，互不影响。
- 数值/长度取值范围（ADR-038）：里程为非负整数；上牌年份区间 1980–2100；
  过户次数为非负整数、起点为 0；车况描述长度上限 500 字。超出范围返回 VALIDATION_ERROR。
- 草稿保存不强制校验以上必填字段是否非空，仅在发布动作时才强制校验（ADR-035）。

**选填（与能源类型联动）**：排量（油车/插混/增程适用）、电耗（纯电/插混/增程适用）、电池度数（纯电/插混/增程适用）

- 前端根据能源类型展示/隐藏对应输入项；服务端同时做强校验，不适用的字段传非 null 值
  返回 VALIDATION_ERROR（INAPPLICABLE_TO_ENERGY_TYPE），维持已实现现状（ADR-110，
  取代 ADR-038 第1条）。

**后台专用**：车架号（VIN）——仅管理后台录入和展示，前台不展示，展示时只露后六位；
保存（创建/编辑）时校验唯一性，与已存在车辆的 VIN 重复则拒绝保存（ADR-036，修正 ADR-002 原"不要求全局唯一"）。
管理后台列表关键字搜索对 VIN 按展示的后六位匹配，不支持输入完整车架号搜索（ADR-037）。

**不做**：车牌号、变速箱、排放标准、事故记录

## 发布前置条件

见 ADR-003。发布（草稿→已上架、已下架→重新上架）时强制校验：
- 图片数量 ≥ 4 张（依赖 F-003 数据）
- 价格已填写（依赖 F-004 数据，允许填具体数值或"面谈"，只要求非空）

任一条件不满足则拒绝发布，返回明确的缺失项提示。校验逻辑在 F-001 的发布动作里执行。

已上架车辆若因 F-003/F-004 数据变动导致事后不再满足以上条件（如图片被删至 4 张以下），
维持已上架状态不变，不做自动降级或强制提示，这是有意选择而非遗漏（ADR-038）。

## 各端职责

**服务端**：车辆用系统自动生成的技术主键作跨 feature 关联锚点；编辑接口加乐观锁防覆盖写、
创建接口加幂等键防重复提交；`/public/*` 接口严格按 status 过滤，下架后前台立即不可见，
不做缓存延迟；记录基本操作日志（操作人/时间/车辆ID/状态变更），只落库不做查看页面，
本期不设保留期/清理策略。见 ADR-005、ADR-006、ADR-038。
乐观锁冲突（VEHICLE_VERSION_CONFLICT）仅返回错误，不在 details 中回传服务端当前最新数据（ADR-038）。

**管理后台**：列表页支持按状态筛选、按关键字搜索，默认展示全部状态（含草稿），不做默认过滤（ADR-038）；
不做导出功能。列表契约仍不返回价格（价格归 F-004）；卡片可展示当前价，数据来自列表之后对每车并行
`GET` 价格接口（及封面所需的 images），一次 setState 收齐（ADR-113），**不是**列表响应字段。
录入交互（ADR-112 / ADR-113，不改契约）：
- 新建为两段式：界面标明「步骤 1/2」，创建成功后再上传图片与报告（图片仍要求车辆已存在）。
- 新建与编辑共用**单一 draft 状态**（实现重构，能力不变）；草稿可空、发布校验仍按 ADR-035 / ADR-003。
- 品牌/车型标「建议填写」，草稿保存仍允许空（ADR-035）。
- 上牌年/里程/过户次数就地校验：控件上牌年 1980–当年、里程 ≥0、过户 0–20；
  错误出现在该字段下方。服务端范围仍以 ADR-038 为准。
- VIN 创建后只读，并说明「创建后不可修改」。
- 移入回收站须站内二次确认。

## 边界与限制

- 本期不为 F-005（回收站）预留软删除字段，F-005 上线时需对 vehicles 表做迁移（ADR-005）
- 草稿数据在 F-005 上线前无法清除/作废，是已知限制（ADR-006）
- 不做车辆清单导出（ADR-006）
- 价格数据仍完全归 F-004：列表接口不加 `price`/`coverUrl`；卡片展示价走独立价格接口兜底（ADR-007 数据归属 + ADR-113 展示口径）
- 不做批量下架；下架仅单车（ADR-113）
- 车辆规模"100 台以内"是当前值非长期上限，技术方案需按可增长设计（ADR-007）
- 管理后台权限：只有一种管理员角色，无只读/审核账号，不设审批流程（已在 docs/product/overview.md
  角色部分确认，对应 /conflicts 问题 9）
- 车辆下架时 F-003 图片/报告不联动处理（ADR-010）
- F-005 删除：草稿 / 已上架 / 已下架均可直接进回收站（ADR-023）
