## 我理解的需求

F-005 是管理后台能力：车辆删进回收站、可恢复为草稿、约 1 个月后自动彻底清除。前台删除后必须立即不可见。ADR-001：不做微信小程序。本评审看回收站对「微信内打开 H5 / 分享链接」的影响。

## 我的方案倾向

- 回收站、删除、恢复、到期清除全部只做管理后台 Web。不给前台、不给任何微信端入口。
- 登录态与微信身份无关。禁止用 wx.login / openid 当管理员凭证。
- 前台立即不可见由服务端 `/public/*` 过滤保证。分享卡片无法强制撤回，但落地页必须空白或统一「不存在」。
- 不因本 feature 申请小程序类目或隐私接口。

## 反对/风险
| 严重度 | 问题 | 说明 |
|---|---|---|
| 高 | 微信内打开的前台 H5 若缓存/分享卡片未失效 | 点开若命中缓存的详情 JSON，访客仍能看到已删车。必须由服务端对已进回收站的公开查询一律按不存在处理。 |
| 中 | 彻底清除后对象存储文件若仍可通过旧 URL 访问 | 微信内长按保存的图/报告链接会变成幽灵资源。 |
| 中 | 恢复为草稿后若公开接口过滤不严 | 可能把草稿重新暴露给分享链接。 |
| 低 | 误把移动端优先理解成要做小程序回收站 | ADR-001 已否决。 |

## 对其他端的隐含要求

- **服务端 /public/*：** 进入回收站后列表、详情、图片、报告、价格公开接口必须立即当作不存在（建议统一 404）。价格记录不级联抹掉，但公开接口不得因库里还有价格行而返回已删车辆。
- **服务端 /admin/*：** 删除/恢复仅管理后台会话可调。恢复后必须是草稿。
- **前台 Web（含微信内置浏览器）：** 不得本地缓存整车详情长期有效。无登录、无 openid。
- **F-002：** 删除后落地页必须与列表一致不可见。
- **F-003：** 进回收站期间公开不可拉图/报告。彻底清除是否删对象存储须本 feature 裁决。
- **F-001：** 扩展在管 → 回收站 → 草稿；回收站中禁止走发布/下架/改价。

## 我需要别人回答的问题

1. 删除允许作用于哪些状态？（问题 25）
2. 「立即不可见」是否包含公开接口缓存最长可接受多久？微信分享卡片残留标题/封面是否可接受？
3. 彻底清除时对象存储是否物理删除？
4. 彻底清除后价格记录仍保留时，管理后台能否按已清除车辆检索？
5. 恢复为草稿后公开 URL 是否复用？
6. 到期 1 个月的起算点与时区？
7. 是否允许回收站内「立即彻底清除」？
8. 普通管理员能否恢复他人删除的车？
9. 公开侧对已进回收站的详情，统一 404 还是 200+ 空态？是否允许文案提及「已删除」？
