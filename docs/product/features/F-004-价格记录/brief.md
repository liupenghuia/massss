# F-004 价格记录

> 由用户手写，几句话即可。写完后运行 /review F-004
> 这个文件是历史快照，评审开始后**不要再改**。

## 解决谁的什么问题
管理员需要能设置和调整车辆价格，价格允许填具体数值或"面谈"；每次价格变动要留痕
（变动前后的值和时间），访客在前台能看到当前价格和价格记录。价格显示错误、
价格历史记录丢失或错乱是 principles.md 的零容忍项。

## 成功标准
- 管理员能设置/修改车辆价格，支持具体数值或"面谈"两种形式
- 每次价格变动自动生成一条价格记录（变动前值、变动后值、变动时间），历史记录不可篡改
- 访客在前台能看到车辆当前价格和价格变动记录
- F-001 的发布校验能读取到"价格是否已填写"这个状态（ADR-003 依赖项，允许"面谈"视为已填写）
- 车辆核心信息（F-001）不包含价格字段，价格完全由本 feature 独立管理（ADR-007）

## 明确不做
- 不做价格审批流程
- 不做批量改价
- 不做促销/折扣机制
