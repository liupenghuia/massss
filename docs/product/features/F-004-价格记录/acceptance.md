# F-004 价格记录 — 验收标准

> 勾选说明：`☑` = 本轮已验证；`☐` = 仍需人工点验。

| # | 场景 | 操作路径 | 预期 | 通过 |
|---|---|---|---|---|
| 1 | 首次设价 | 车辆详情设一口价 | 写一条 from=unset 的记录；当前价正确 | ☑ |
| 2 | 金额存分 | 设价 128000.50 后查库 | `to_amount = 12800050`（分）；接口仍返回元 | ☑ |
| 3 | 相同金额不写记录 | 再提交完全相同价格 | unchanged=true，记录条数不增 | ☐ |
| 4 | 10.1 与 10.10 等价 | 分别提交 | 第二次 unchanged（按分比较） | ☑（单测） |
| 5 | 改价留痕 | 改成另一金额 | 新记录 from=旧价 to=新价；列表新到旧 | ☐ |
| 6 | 面谈 | 设为面谈 | type=negotiable，前台「面议」 | ☐ |
| 7 | 操作人展示账号名 | 后台价格记录列表 | 显示 loginName，非裸数字 id | ☑（JOIN + UI） |
| 8 | 创建带初始价同事务 | 新建车带 initialPrice | 车与首条价同事务；失败则都没有 | ☑（代码路径） |
| 9 | 公开仅已上架 | 草稿车调公开价格接口 | 404 | ☑ |
| 10 | 当前价按 id 最大 | 并发/时钟场景（单测+实现） | ORDER BY id DESC，非 created_at | ☑（实现） |
