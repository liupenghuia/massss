## 背景

管理后台必须登录才能使用。账号仅两级：管理员（车辆/图片/价格/回收站全部业务操作）、
超级管理员（管理员全部权限 + 账号生命周期管理）。前台无用户体系，不得复用后台会话。

## 用户故事

- 作为超级管理员，我给新同事开一个管理员账号，系统生成初始口令，我口头告诉他。
- 作为管理员，我首次登录被要求改密，之后可以正常使用后台全部业务功能。
- 作为超级管理员，我发现一个账号异常，立刻停用它，该账号下一次请求即失败，无法再改任何数据。
- 作为管理员，我忘了密码，请超级管理员帮我重置。

## 状态机

账号状态为两个正交维度：

| 维度 | 取值 |
|---|---|
| 角色 | `admin`（管理员）/ `super_admin`（超级管理员） |
| 启用状态 | `active`（启用）/ `disabled`（停用） |

- 停用是状态转移，**不做物理删除**，可重新启用。
- 系统**禁止**将最后一个处于 `active` 的 `super_admin` 停用。

## 各端职责

### 服务端
- 会话存服务端（可吊销），不使用长期 JWT 塞角色。
- 每次 `/admin/*` 请求实时校验账号未停用；停用/改密后作废该账号全部现有会话。
- 会话有效期 8 小时滑动过期；同一账号允许多端同时登录。
- 未登录 → `401`；已登录但角色不足或已停用 → `403`。
- 密码最少 8 位含字母数字；连续 5 次登录失败锁定该账号 15 分钟。
- 账号管理写接口（建号/停用/启用/重置密码）服务端二次校验超级管理员角色。
- 部署时种子脚本创建首个超级管理员，口令通过环境变量注入，不进仓库。
- 账号生命周期（创建/停用/启用/重置密码）落库审计，本期不做查看页。

### 管理后台
- 登录页 URL 不在 `/admin/*` 前缀下，允许未登录访问；其余全部要求登录。
- 超级管理员可见「新建管理员」「停用/启用账号」「重置密码」入口；管理员不可见。
- 账号列表默认展示全部账号（含已停用），带状态标签。
- 新建账号：填登录名提交，系统生成随机初始口令，创建成功页展示一次。
- 首次登录（含密码重置后）强制跳转改密页面，改密前无法使用其他功能。

### 前台
- 无用户体系，`/public/*` 不校验、不读取任何后台会话。

## 权限矩阵

| 操作 | 管理员 | 超级管理员 |
|---|---|---|
| 车辆录入/编辑/上下架 | ✅ | ✅ |
| 改价 | ✅ | ✅ |
| 图片/评估报告管理 | ✅ | ✅ |
| 删除到回收站/恢复 | ✅ | ✅ |
| 新建管理员账号 | ❌ | ✅ |
| 停用/启用管理员账号 | ❌ | ✅ |
| 新建/停用其他超级管理员 | ❌ | ✅（不能停用自己） |
| 修改他人角色（升降级） | ❌ | ✅（不能把最后一个启用超管降级） |
| 重置他人密码 | ❌ | ✅ |
| 修改自己的密码 | ✅ | ✅ |

## 账号与登录名规则

- 登录名全局唯一，**创建后不可修改**；账号停用后其登录名**永久占用**，不可被新账号复用。
- 操作日志与价格记录的「操作人」字段**落库存账号稳定 ID**，展示时实时查询当前登录名。
- 忘记密码由超级管理员重置（生成新随机口令展示一次），重置后同样触发首次强制改密。

## 边界与限制

### 明确不做
- 不做前台注册/登录/收藏。
- 不做微信/企微身份登录、不做小程序登录（ADR-001）。
- 不做只读账号、审核流、自定义权限矩阵。
- 不做多租户。
- 不做字段级分权——两级角色的业务能力完全相同，权限差只在「管账号」。
- 不做账号物理删除。
- 不做账号生命周期审计查看页（落库但不做界面）。
- 不做邮箱/短信找回密码。

### 已知限制
- 停用后最多允许一次已在服务端执行中的写请求跑完，不强制中断进行中的事务。
- 允许多端同时登录，不做账号共享风控。
- 无审计查看页，问题排查需开发直接查库。
- 登录名永久占用不可回收，误建账号的登录名永久作废。

### 部署
- 管理后台与前台**不同域部署**，天然隔离会话 Cookie，无需额外分区方案。
