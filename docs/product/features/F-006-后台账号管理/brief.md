# F-006 后台账号管理

> 由用户手写，几句话即可。写完后运行 /review F-006
> 这个文件是历史快照，评审开始后**不要再改**。

## 解决谁的什么问题
管理后台必须登录才能用。需要两级账号：管理员（录入/编辑/上下架/改价/删除到回收站）、
超级管理员（管理员的全部权限 + 生成、分配、停用管理员账号）。没有只读账号、没有审核员、
不设审批流（overview 已确认）。前台没有用户体系。

## 成功标准
- 未登录不能调用 `/admin/*`，不能进入管理后台页面
- 超级管理员能生成、分配、停用管理员账号；被停用的账号立即不能再登录、不能再改数据
- 管理员不能创建/停用别人的账号
- 登录态能作为 F-001/F-003/F-004 操作日志和价格记录「操作人」的标识
- 两级角色都能做车辆/图片/价格/回收站的业务操作（权限差只在「管账号」）

## 明确不做
- 不做前台注册/登录/收藏
- 不做微信/企微身份登录、不做小程序登录（ADR-001）
- 不做只读账号、审核流、自定义权限矩阵
- 不做多租户
- 本期不要求管理员「不能改价」这类字段级分权（与既有 ADR「登录即可改价」对齐，本 feature 只收口账号生命周期）
