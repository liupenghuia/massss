# F-002 前台车辆展示 — 验收标准

> 每条都必须是**用户能自己点一遍验证**的。
> 写不出操作路径的条目，说明需求还没想清楚。

| # | 场景 | 操作路径 | 预期 | 通过 |
|---|---|---|---|---|
| 1 | 免登录浏览列表 | 无痕窗口打开前台首页 | 直接看到在售车辆列表，无任何登录提示 | ☐ |
| 2 | 列表卡片信息完整 | 首页看任一卡片 | 卡片同时有封面图、关键参数、当前价，且只发出一次列表请求（DevTools 确认无逐条 images/price 请求） | ☐ |
| 3 | 列表排序 | 首页对照后台车辆 id | 顺序为 id 降序；页面无排序切换入口（筛选/搜索见 36-42） | ☐ |
| 4 | 列表分页 | 后台造 25 台已上架车，刷新首页 | 首屏 20 条，有下一页/加载更多；不一次拉全量 | ☐ |
| 5 | 空列表 | 把所有车下架，打开首页 | 显示「暂无在售车辆」，页面不报错 | ☐ |
| 6 | 面议文案 | 打开一辆价格类型为面谈的车详情 | 价格处显示「面议」；**无** 0、「0.00 万」或空占位 | ☐ |
| 7 | 金额格式 | 打开一辆标价 128000 的车 | 显示「12.80 万」 | ☐ |
| 8 | 两端用词一致 | 对比后台该车价格展示 | 后台同样显示「面议」 | ☐ |
| 9 | 价格历史全量 | 给一辆车录 8 条价格记录，打开详情 | 8 条全部展示，新到旧排序，每条含类型+金额+日期，无分页无「查看更多」 | ☐ |
| 10 | 价格历史不泄漏 | 同上，查看页面与接口响应 | 无操作人、操作账号、内部备注字段 | ☐ |
| 11 | 公开响应不泄漏 | DevTools 看 `/public/*` 响应 | 无 VIN / vinMasked / operatorId / version / 后台备注 | ☑ |
| 12 | 空值隐藏行 | 打开一辆排量为空的燃油车详情 | 排量整行不渲染，无空白行、无「-」 | ☐ |
| 13 | 数字 0 是有效值 | 打开一辆里程 0、过户 0 的车 | 里程与过户次数正常显示 0，不被当空值隐藏 | ☐ |
| 14 | 草稿不可见 | 直接访问某草稿车的详情 URL | 页面显示「该车辆不存在或已下架」，接口返回 404 VEHICLE_NOT_FOUND | ☑ |
| 15 | 已下架不可见 | 直接访问某已下架车的详情 URL | 同上，**且不出现「已下架」字样** | ☑ |
| 16 | 乱猜 id | 访问 `/vehicles/999999` | 同上，与草稿/下架的响应和文案完全一致，无法区分 | ☑ |
| 17 | 下架零延迟 | 后台下架一辆车，立刻请求其公开详情接口 | 立即 404，无需等待；响应头无缓存（TTL=0） | ☐ |
| 18 | 改价零延迟 | 后台改价后立刻刷新前台详情 | 立即看到新价 | ☐ |
| 19 | 编辑立即生效 | 后台改一辆已上架车的参数，刷新前台 | 立即看到新参数 | ☐ |
| 20 | 旧直链仍可打开 | 下架一辆车后，打开之前复制的图片直链 | 图片仍返回 200 可打开；**同时**该车详情页 404 —— 两者都判通过 | ☐ |
| 21 | 图片顺序与灯箱 | 打开详情点第 3 张图 | 顺序与后台一致；打开灯箱，不跳出页面；手机端可左右滑动切换 | ☐ |
| 22 | 图片说明为空 | 打开一辆有图但说明为空的车 | 说明区不渲染、不占位 | ☐ |
| 23 | 无评估报告 | 打开一辆无报告的车详情 | 整个报告区块不渲染，无置灰入口 | ☐ |
| 24 | 多份报告 | 打开一辆有 2 份报告的车 | 按服务端顺序列出文件名+上传时间；无上传人、无「主报告」标记 | ☐ |
| 25 | 报告打开降级 | 在微信 iOS 内点报告 | 新标签打开 / 当前 WebView 打开 / 提示「请在浏览器中打开」—— **三者任一均通过**；不弹文件权限申请 | ☐ |
| 26 | 5xx 错误态 | 断服务端后刷新列表 | 显示「加载失败，请重试」+ 可点的重试按钮 | ☐ |
| 27 | 无半残页面 | 制造价格接口失败 | 不出现「车还在、价没有」的半残页；按统一错误态处理 | ☐ |
| 28 | 后台复制前台链接 | 后台打开一辆已上架车详情 | 有可复制的前台 URL，粘贴到无痕窗口能正常打开 | ☐ |
| 29 | 未上架无预览入口 | 后台打开一辆草稿车详情 | 前台链接入口置灰并注明原因，无任何预览方式 | ☐ |
| 30 | 禁止 admin 冒充 | 用已登录 admin 的浏览器访问某草稿车前台 URL | 仍然 404，admin cookie 不生效 | ☐ |
| 31 | OG 头 | 查看详情页 HTML 源码 | 有 og:title（品牌车型）、og:description（关键参数）、og:image（首图） | ☐ |
| 32 | 无微信专属能力 | 查看页面加载的脚本 | 无微信 JS-SDK，无 OAuth 跳转，无 openid 获取 | ☐ |
| 33 | 无访问统计 | 查看网络请求 | 无埋点、无浏览次数上报、无第三方统计脚本 | ☐ |
| 34 | 限流生效 | 短时间高频请求公开列表接口 | 触发 IP 级速率限制 | ☐ |
| 35 | 响应式 | 375px 宽手机竖屏、1024px 桌面各走一遍列表+详情 | 布局正常无横向滚动，关键信息不被截断 | ☐ |
| 36 | 关键字搜索 | 搜索框输入某品牌名 | 只返回该品牌车辆；DevTools 确认是带查询参数的新请求，**不是**本地过滤 | ☐ |
| 37 | 价格区间筛选 | 筛选 10-20 万 | 结果全部落在区间内 | ☐ |
| 38 | 面议不进价格区间 | 同上，且库中有面议车 | 面议车**不出现**在结果中；页面无「含面议」开关 | ☐ |
| 39 | 面议不受其他维度限制 | 用关键字搜该面议车的品牌 | 面议车正常出现在结果中 | ☐ |
| 40 | 条件组合 | 同时设关键字 + 价格区间 + 年份 + 里程 | 结果同时满足全部条件（AND 语义） | ☐ |
| 41 | 筛选后仍遵守既有规则 | 任一筛选条件下翻页 | 结果仍为 id 降序、每页 20 条、无草稿/已下架车辆混入 | ☐ |
| 42 | 清空条件 | 清空全部筛选 | 回到全量已上架列表，与首页一致 | ☐ |
| 43 | 后台筛选未被改动 | 管理后台列表页 | 仍为「按状态筛选 + 关键字搜索」，未新增价格/年份/里程筛选（ADR-006 范围） | ☐ |
| 44 | 详情深链 | 无痕窗口打开 `/vehicles/{已上架 id}` | 直接进入该车详情，无需先经过列表 | ☐ |
| 45 | 详情深链 404 | 打开 `/vehicles/999999` | 页面「该车辆不存在或已下架」，与草稿/下架文案一致 | ☐ |
| 46 | 列表深链 | 筛选后把地址栏 URL 粘到无痕窗口 | 同一页码与同一组筛选条件 | ☐ |
| 47 | 后台复制链接 | 后台复制已上架车前台 URL | 形态为 `{origin}/vehicles/{id}`，无痕可打开 | ☐ |
