## 背景

访客侧只读展示：不登录、打开链接即可浏览已上架车辆的列表与详情。
交付形态为 Web（ADR-001），不做微信小程序。
本 feature 不新增任何写入能力，只消费 `/public/*` 读接口。

## 用户故事

- 作为访客，我打开分享来的链接，无需登录就能看到在售车辆列表（封面图 + 关键参数 + 当前价）。
- 作为访客，我能按品牌车型关键字、价格区间、上牌年份、行驶里程筛选出符合预算和需求的车。
- 作为访客，我点进某辆车，能看到全部图片、完整参数、全部价格变动轨迹、评估报告。
- 作为运营，我在管理后台能复制某辆已上架车的前台链接，直接发给客户。

## 状态机

本 feature **无独立状态机**。可见性唯一信服务端 `published` 硬过滤：

| 车辆状态 | 公开接口 | 前台页面 |
|---|---|---|
| published | 200 正常返回 | 正常展示 |
| draft | 404 VEHICLE_NOT_FOUND | 「找不到该车辆」 |
| unpublished（已下架） | 404 VEHICLE_NOT_FOUND | 「找不到该车辆」 |
| 不存在 / 乱猜 id | 404 VEHICLE_NOT_FOUND | 「找不到该车辆」 |
| 未来的删除态（F-005） | 必须同样 404 | 同上 |

已上架车辆编辑后立即进入前台投影（ADR-004/008），无延迟发布、无审核态。

## 各端职责

### 服务端
- `GET /public/vehicles`：**聚合读模型**，一次返回卡片全部数据 —— F-001 公开文本字段 +
  封面缩略图 URL + 当前价（类型 + 金额）。当前价 = 最新一条价格记录的变动后值，服务端计算。
- 排序固定 `id` 降序；分页 `pageSize = 20`（ADR-019）。
- **搜索与筛选由服务端执行**（ADR-022）：列表接口增加可选查询参数，过滤后再分页返回。
- 缩略图 URL 由服务端字段保证，**不由前端拼 CDN 参数**。
- 公开响应**禁止**出现：VIN / vinMasked、操作人 / operatorId、内部备注、version。
- 公开 GET **禁止缓存，TTL = 0**（ADR-005 / ADR-019）。
- 公开接口加基础 IP 级限流。
- 详情页服务端渲染 OG meta 头（标题 = 品牌车型，描述 = 关键参数，封面 = 首图）。

### 前台（哑终端）
- 只渲染 `/public/*` 已返回的数据，**禁止**请求 `/admin/*`。
- **禁止**传 `status`、**禁止**二次判断可见性。
- **禁止**任何浏览器内的本地过滤 / 本地重排 / 本地排序切换。搜索筛选只能转成查询参数交给服务端（ADR-022）。
- **禁止**自行计算当前价。
- 图片按接口返回顺序展示，不得重排。

### 管理后台
- 车辆详情页对**已上架**车辆展示可复制的前台 URL；未上架时该入口置灰并注明原因。
- 不做未发布预览，不做独立 admin 预览模型，禁止 admin cookie 冒充 `/public`。
- 本包不给后台加新菜单、筛选、批量、导出。

## 搜索与筛选（ADR-022）

服务端执行，全部为可选查询参数，不传即为全量已上架列表。条件可组合，组合语义为 **AND**。

| 维度 | 形态 |
|---|---|
| 关键字 | 单一搜索框，模糊匹配**品牌 + 车型** |
| 价格区间 | 按当前价的最小值 / 最大值 |
| 上牌年份 | 年份区间 |
| 行驶里程 | 里程区间 |

- **面议车辆（无金额）在使用价格区间筛选时一律不进结果集**，不提供「含面议」开关。
  关键字、年份、里程三个维度不受此限制。
- 筛选结果同样遵守：`published` 硬过滤、id 降序、`pageSize = 20`。
- 管理后台仍为「按状态筛选 + 关键字搜索」（ADR-006，属 F-001），本包不动。
  两端筛选能力不对称是已知且接受的现状。

## 展示规则（唯一定稿值，同时作为测试夹具）

### 价格
| 项 | 规则 |
|---|---|
| 面谈文案 | 前台对价格类型做唯一死映射，面谈渲染为「**面议**」；后台用同一词 |
| 金额格式 | 以万为单位、保留两位小数、后缀「万」。例：`128000` → 「12.80 万」 |
| 面谈金额为空 | 只渲染「面议」，**禁止**显示 0 / 「0.00 万」/ 空占位 |
| 价格历史条数 | **全量展示**，不分页、不截断 |
| 价格历史排序 | **新到旧** |
| 每条内容 | 价格类型 + 金额 + 变动日期 |
| 禁止字段 | 操作人、操作账号、任何内部备注 |
| 前后台差异 | 无。后台与前台同为全量 |

### 空值映射表
| 服务端值 | 前台渲染 |
|---|---|
| `null` | **隐藏整行**（字段不渲染） |
| 空字符串 `""` | **隐藏整行** |
| 数字 `0` | 有效值，照常展示（里程 0、过户 0 正常显示） |

无评估报告 → 整个报告区块不渲染。图片说明为空 → 说明区不渲染、不占位。

### 评估报告
- 无报告：整块隐藏，不展示置灰入口。
- 多份：按服务端返回顺序列出**文件名 + 上传时间**；不展示上传人，无「主报告」。
- 打开降级链（三种结果均判通过）：新标签打开 → 被拦截则当前 WebView 打开 → 仍失败则提示「请在浏览器中打开」。
- 禁止为保存文件申请任何文件系统权限。

### 图片
- 点击打开**灯箱**（手机端左右滑动切换），不跳出详情页。

### 错误态与空态（属本 feature 验收）
| 场景 | 文案 |
|---|---|
| 5xx / 超时 | 「加载失败，请重试」+ 重试按钮 |
| 详情 404 | 「找不到该车辆」 |
| 空列表 | 「暂无在售车辆」（**允许空态上线**） |

禁止用部分成功的数据拼出「车还在、价没有」的半残页面。

## 边界与限制

### 明确不做（可验收的否定条款，ADR-021）
- 不做前台访问统计：浏览次数、链接打开统计、访问审计；不得为统计走微信 OAuth。
- **任何里程碑都不做微信小程序**（含转发壳）。将来要做必须新开 feature 并改 `docs/principles.md`。
- 不做前台置顶 / 推荐位 / 运营配置台。
- 不调用微信 JS-SDK、不绑公众号、不做微信自定义分享卡片。
- 不做未发布预览。

### 已知限制
- 对象存储用**永久公开直链，不开 Referer 防盗链、不用过期签名**。
  车辆下架后页面 404，但旧文件直链仍返回 200 —— 两者是不同层面的事，联调用例**均判通过**（ADR-009/019）。
- 已上架编辑立即对客生效，运营改错只能先下架再改。
- 车辆 id 可被按序遍历，书面接受（已上架车本就是对外公开信息）。
- 微信可能不读取 OG 头，分享出去可能只是裸链接样式。
- 禁用 CDN 缓存放弃了加速与成本优化，当前一百台规模内无压力。

### 回收站
本期**只验收 `draft` / `unpublished` 不可见**。「回收站中不可见」记为 F-005 上线时的回归项。
不变量：任何未来引入的删除态都必须同样被公开查询排除。

## 测试矩阵（ADR-021）

- 自动化：**公开接口契约测试为主** —— 可见性过滤、404 语义、分页、字段泄漏。
- 手动抽检：微信 iOS / 微信 Android 内置浏览器 + 系统 Safari / Chrome。微信 PC **不必测**。
- 响应式：手机竖屏最小 **375px**，桌面最小 **1024px**。
- 不引入浏览器 E2E 自动化框架。

## 搜索与筛选补充边界（ADR-029）

- 区间参数下限 > 上限：`400 VALIDATION_ERROR`。
- 上牌年份区间约束 `1980 ~ 2100`。
- 分页越界（筛选后命中数 < 请求页起始位置）：返回空 `items`，不报错。
- `keyword`：服务端 trim + 不区分大小写模糊匹配。
- 金额精度：服务端按分为单位比较，不依赖 schema `multipleOf` 浮点判定。
