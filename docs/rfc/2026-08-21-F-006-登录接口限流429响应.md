# RFC: F-006 登录接口限流 429 响应补全

Status: Accepted
Feature: F-006
相关 ADR: ADR-103

## 背景
`contracts/openapi.yaml` 中 `/admin/auth/login` 的 description 已写明"加基础 IP 级速率限制"，
但 `responses` 只列了 200/400/403/500，没有 429。ADR-103 裁决登录锁定与 IP 限流同时触发时，
IP 限流优先，超限返回 `TOO_MANY_REQUESTS`（该错误码已在 contracts/errors.yaml 中定义，
此前用于 F-002 公开接口限流），但 `/admin/auth/login` 的响应定义里从未声明过 429，
属于契约遗漏，不是本次新引入的语义。

## 提案
在 `contracts/openapi.yaml` 的 `/admin/auth/login` responses 里补充：
```
"429": { $ref: '#/components/responses/TooManyRequests' }
```
（`TooManyRequests` 可复用公开接口限流已建的同一个 responses 组件，或按登录场景单独定义，
由 contract-keeper 判断是否复用。）

本提案仅描述诉求，不直接改 contracts/。
