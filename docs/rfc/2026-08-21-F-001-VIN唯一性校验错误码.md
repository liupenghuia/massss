# RFC: F-001 VIN 唯一性校验错误码

Status: Accepted
Feature: F-001
相关 ADR: ADR-036

##背景
ADR-036 裁决车架号（VIN）保存（创建/编辑）时需要校验唯一性，重复则拒绝保存。
当前 contracts/errors.yaml 没有对应错误码，adminCreateVehicle / adminPatchVehicle
的失败响应目前只能落到通用的 VALIDATION_ERROR，但 VALIDATION_ERROR 语义是"参数格式不合法"，
与"参数格式合法但与已有数据冲突"不是一回事，且冲突态更适合 409 而非 400。

## 提案
在 contracts/errors.yaml 新增错误码：

- code: `VEHICLE_VIN_DUPLICATE`
- httpStatus: 409
- fixedMessage: false
- message: 该车架号已被其他车辆使用
- details: `{}`
- note: adminCreateVehicle / adminPatchVehicle 时 vin 与其他车辆（含回收站中未彻底清除的车辆，
  彻底清除后的车辆是否释放 VIN 待 F-005 侧另行裁决）重复时触发。

需要 contract-keeper 在 contracts/errors.yaml 与 contracts/openapi.yaml（adminCreateVehicle、
adminPatchVehicle 两个接口的 responses）落地，本提案仅描述诉求，不直接改 contracts/。

## 待确认
- 回收站中（trashedAt 不为空、未彻底清除）的车辆是否占用 VIN 唯一性名额？
  与 F-005 conflicts.md 问题 6（VIN/主键唯一性约束是否覆盖 purged=true 记录）属同一议题，
  建议合并到 F-005 裁决批次一并处理。
