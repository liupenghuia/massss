# ADR-007 价格字段归属与车辆规模假设

Status: Accepted
Date: 2026-08-19
Feature: F-001, F-004
Supersedes: -

## Context

`/conflicts F-001` 问题 5、14：车辆卡片本身要不要带价格字段、"一百台以内"
是当前规模还是长期上限。

## Decision

- 车辆核心字段（F-001）不包含价格字段，价格完全由 F-004 独立管理，
  F-001 的车辆记录里不出现任何价格相关列。
- "一百台以内"是当前规模，不是长期上限，后续车辆数量会增长。技术方案
  （分页、索引等）需要按可增长设计，不能假设固定不超过 100 台的硬编码上限。

## Consequences

+ F-001 与 F-004 职责边界清晰，价格变更、价格历史完全在 F-004 内部演进，
  不影响 F-001 的 contracts。
+ 提前明确规模会增长，避免 F-001/F-002 等 feature 按"100 台封顶"做简化实现
  （如不分页），未来数据量上来后要返工。
- F-001 发布校验（ADR-003）仍需依赖 F-004 数据判断价格是否已填写，接口耦合依然存在，
  只是数据本身不落在 F-001 表里。
- 具体增长速度、上限量级仍未知，分页/索引策略只能按"预期会增长"的方向设计，
  无法现在给出精确容量规划。
