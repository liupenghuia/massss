# ADR-006 F-001 管理后台运营能力范围

Status: Accepted
Date: 2026-08-19
Feature: F-001
Supersedes: -

## Context

`/conflicts F-001` 问题 10、12、13、18：操作日志、列表筛选搜索、导出 Excel、
草稿清除手段，是运营侧可用性范围的界定问题。

## Decision

- 记录基本操作日志（操作人、操作时间、车辆 ID、变更前后的状态），只落库，
  不做专门的日志查看页面。
- 管理后台列表页支持按状态筛选、按关键字搜索，属于 F-001 范围。
- 本期不做车辆清单导出（Excel 等），后续有实际运营需求再评估。
- 草稿数据在 F-005（回收站）上线前，管理员没有清除/作废误建草稿的手段，
  这是本期已知限制，用户已接受。

## Consequences

+ 操作日志兜底了 principles.md「后台账号越权」零容忍项的可追溯性。
+ 列表筛选搜索覆盖了运营最高频的查找场景。
+ 不做导出避免了本期过度设计。
- 草稿无法清除，误建的草稿会一直留在列表里（可用筛选功能过滤，影响有限）。
- 操作日志本期无查看界面，运营自己排查不便，只能靠开发协助查数据库。
