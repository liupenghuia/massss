# F-001 车辆信息管理

> 由用户手写，几句话即可。写完后运行 /review F-001

## 解决谁的什么问题
管理员目前没有统一的地方录入和维护车辆基础信息（车辆卡片核心字段），
需要能新建、编辑车辆卡片，并控制车辆的上架/下架状态。

## 成功标准
- 管理员能新建一辆车的信息，保存为草稿（暂不发布）或直接发布上架
- 管理员能编辑已有车辆的信息
- 管理员能对已上架车辆执行下架、对已下架车辆执行重新上架
- 全程不需要他人审核，管理员保存后可自行直接发布

## 明确不做
- 不做价格调整与价格记录（归 F-004 价格记录）
- 不做删除、回收站、恢复（归 F-005 回收站）
- 不做图片、评估报告的上传与展示（归 F-003 图片与评估报告）
- 不做访客端展示逻辑（归 F-002 前台车辆展示）
