# F-003 图片与评估报告

> 由用户手写，几句话即可。写完后运行 /review F-003
> 这个文件是历史快照，评审开始后**不要再改**。

## 解决谁的什么问题
管理员需要给每辆车上传图片（最少 4 张，无上限）和第三方评估报告文件，能调整图片顺序、
给单张图片加说明文案。图片和评估报告是核心资产，也是长期主要成本项（对象存储 + CDN）。

## 成功标准
- 管理员能给车辆上传图片，数量下限 4 张，无上限
- 管理员能拖拽调整图片顺序，排序后保存或发布
- 管理员能给单张图片添加说明文案（图片说明，区别于挂在整台车上的"车辆描述"），条数无上限
- 管理员能上传评估报告文件（PDF、PNG、jpeg），直接展示
- 图片和评估报告存储用对象存储 + CDN，不落应用服务器本地磁盘
- 访客在前台能查看车辆的全部图片、图片说明和评估报告
- 车辆用于关联图片/报告的标识，用 F-001 的技术主键（ADR-005），不是车架号

## 明确不做
- 不做图片在线编辑（裁剪、滤镜等），只做上传、排序、说明、展示
- 不做视频
- 不做图片审核/审批流程
- 发布前是否要求已有图片，由 F-001 的发布逻辑校验（ADR-003），不在本 feature 内实现
- 车辆下架时图片是否需要联动处理，留待本 feature 评审时裁决（F-001 conflicts.md 问题 24）
