# F-002 前台车辆展示

> 由用户手写，几句话即可。写完后运行 /review F-002
> 这个文件是历史快照，评审开始后**不要再改**。

## 解决谁的什么问题
访客不需要登录，用手机打开链接就能浏览已上架车辆的列表和详情（核心字段、图片及图片说明、
评估报告、当前价格和价格记录）。前台是哑终端：只渲染 `/public/*` 已返回的数据，
不做上架过滤、不做「面谈还是数字」的业务判断。交付形态为 Web（ADR-001），不是小程序。

## 成功标准
- 访客能看到已上架车辆列表；点进详情能看到该车公开信息、图片（含说明）、评估报告、当前价格
- 访客能看到价格变动记录；展示条数、是否分页、面谈文案（如「面议」）在本 feature 内定稿
- 草稿、已下架、回收站中的车辆前台不可见（依赖服务端按 published 过滤，前台不另做状态判断）
- 评估报告按已有约定新标签打开原文件（ADR-010）；图片用公开接口返回的顺序和直链展示
- 手机竖屏为第一目标，桌面端兼容

## 明确不做
- 不做登录、注册、收藏、询价、对比、下单、支付
- 不做 SEO 导向的服务端渲染/站点地图（发链接给客户看即可）
- 不做微信小程序；不做仅微信可用的专属能力
- 不在前台实现车辆状态过滤或价格类型判断（归服务端 / F-001、F-004 契约）
- 不改车辆、图片、价格的写入接口
