# F-005 回收站 — 验收标准

> 每条都必须是**用户能自己点一遍验证**的。
> 写不出操作路径的条目，说明需求还没想清楚。

| # | 场景 | 操作路径 | 预期 | 通过 |
|---|---|---|---|---|
| 1 | 草稿可删除 | 后台对一台草稿车点删除 | 二次确认后消失于在管列表，出现在回收站列表 | ☐ |
| 2 | 已下架可删除 | 对一台已下架车点删除 | 同上 | ☐ |
| 3 | 已上架直接删除 | 对一台已上架车点删除（不先下架） | 直接进回收站；操作日志同时出现「下架」与「删除进站」两条 | ☐ |
| 4 | 删除需二次确认 | 点删除按钮 | 弹出确认框，取消则不执行 | ☐ |
| 5 | 前台立即不可见 | 删除一台已上架车后立刻请求其公开详情接口 | 立即 404，无缓存延迟 | ☐ |
| 6 | 在管列表排除回收站车辆 | 删除后查看在管列表 | 该车不出现，且无法通过在管列表的编辑/发布/改价接口操作它 | ☐ |
| 7 | 回收站列表字段 | 打开回收站列表 | 显示原状态、删除时间、到期日/剩余保留天数（服务端计算） | ☐ |
| 8 | 回收站排序 | 连续删除 3 台车 | 列表按删除时间倒序 | ☐ |
| 9 | 回收站搜索分页 | 在回收站列表按品牌关键字搜索 | 正确过滤；结果支持分页 | ☐ |
| 10 | 回收站只读——查看 | 打开回收站中一台车的详情 | 可看到全部图片、评估报告、完整价格历史 | ☐ |
| 11 | 回收站只读——禁止编辑 | 尝试对回收站中车辆调用改核心字段/改价/改图/发布/下架接口 | 全部被拒绝 | ☐ |
| 12 | 回收站期间禁止上传附件 | 对回收站中车辆调用图片上传接口 | 被拒绝 | ☐ |
| 13 | 恢复落草稿 | 恢复一台原本已上架的车 | 恢复后状态为草稿，不自动上架 | ☐ |
| 14 | 恢复无需二次确认 | 点恢复 | 直接执行，无确认弹窗 | ☐ |
| 15 | 恢复后重新发布需校验 | 恢复一台图片不足 4 张的车后尝试发布 | 按 ADR-003 前置校验拒绝发布 | ☐ |
| 16 | 恢复后 URL 复用 | 恢复并重新发布后打开车辆公开详情 | URL 与删除前一致且可正常访问 | ☐ |
| 17 | 重复删除幂等 | 对已在回收站的车再次调用删除 | 幂等成功，`trashedAt` 不变（到期日不刷新） | ☐ |
| 18 | 重复恢复幂等 | 对已恢复的车再次调用恢复 | 幂等成功 | ☐ |
| 19 | 多次循环重算保留期 | 删除→恢复→再删除同一台车 | 第二次删除的到期日相对新的删除时间重新计算 | ☐ |
| 20 | 保留期到期自动清除 | 拨测试时钟至删除后 30×24 小时，等下一次调度周期跑完 | 车辆从回收站列表消失，`purged=true` | ☐ |
| 21 | 清除后不可恢复 | 对已清除的车调用恢复接口 | 返回专用错误码，恢复失败 | ☐ |
| 22 | 恢复优先于清除 | 在清除任务扫描到但尚未处理完该记录前点恢复 | 恢复成功 | ☐ |
| 23 | 无手动彻底清除入口 | 检查回收站界面与接口 | 没有任何「立即清除」按钮或接口 | ☐ |
| 24 | 价格记录不级联删除 | 彻底清除一台有价格历史的车后，管理后台按其 id 检索 | 仍能看到完整历史价格 | ☐ |
| 25 | 已清除车辆管理端只读检索 | 同上 | 只返回只读信息，无法编辑/恢复 | ☐ |
| 26 | 已清除车辆公开端不可见 | 请求已清除车辆的公开详情接口 | 404 VEHICLE_NOT_FOUND | ☐ |
| 27 | 主键不可复用 | 新建一台车 | 新车 id 与任何已清除车辆 id 不重复 | ☐ |
| 28 | 对象存储彻底清除 | 车辆到期清除后（补偿任务跑完），访问其原图片直链 | 图片不可访问（异步删除已完成） | ☐ |
| 29 | 停留期内对象仍可用 | 车辆进回收站但未到期，访问其图片直链 | 图片仍可正常打开（未被提前删除） | ☐ |
| 30 | 权限不限本人 | 用管理员 A 恢复管理员 B 删除的车 | 恢复成功，不因非本人删除而拒绝 | ☐ |
| 31 | 停用账号立即失效 | 停用一个管理员账号后，用其已登录会话尝试删除 | 立刻被拒绝 | ☐ |
| 32 | 操作日志完整 | 依次删除、恢复一台车，等一次清除任务跑完 | 三类操作（删除/恢复/清除）均在日志中留痕，清除记录的操作人为系统账号标识 | ☐ |
| 33 | 不做批量操作 | 检查回收站界面 | 无批量删除、无批量恢复入口 | ☐ |
| 34 | 不做导出 | 检查回收站界面 | 无导出按钮 | ☐ |
