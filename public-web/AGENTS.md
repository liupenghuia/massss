# AGENTS.md（public-web 卖车展示前台）

继承仓库根 AGENTS.md 的全部约定。本文件在冲突时优先。

## 技术栈

- React 19 + TypeScript + Vite
- 视觉以仓库 `车辆管理系统架构/车辆系统统一设计-standalone.dc.html` 的 **1b 前台** 为准（Organic）
- CSS 从 `shared/organic.css` + `shared/shell.css` 引入，与管理后台同一套 token
- **没有** `tailwind.config.js`、**没有** `postcss.config.js`
- 禁止引入 Ant Design 或任何中后台组件库

## 产品定位

这是二手车商品站，不是管理后台。视觉参照电商商品页：大图、突出的价格、清晰的卡片网格。移动端优先。

## 设计 token

token 与组件类以 `shared/organic.css` + `shared/shell.css` 为准（与后台同一套）。
`src/index.css` 只做引入与少量前台布局，**不要**再铺第二套色板或 `@theme` 硬编码。

- 颜色、间距、圆角、字号只取 organic/shell 变量与已有类
- 强调色只出现在价格、主 CTA、促销标签
- 全站一套无衬线字体栈
- 新页面复用 `.btn` `.card` `.tag` `.input` `.pager`；新增全局类走 ADR
- 内联 style 仅动态计算值；最小正文 12px

## 必须复用的基础组件

位于 `src/components/ui/`，新页面一律复用，禁止另起炉灶：

| 组件 | 用途 |
|---|---|
| `<Button>` | primary / secondary / ghost 三档，含 hover / active / disabled / loading 全状态 |
| `<Price>` | 价格展示，大字号 + 强调色，统一千分位与单位 |
| `<SmartImage>` | 所有图片必须走它。内建宽高比锁定、`loading="lazy"`、`srcset`/`sizes`；首屏大图传 `priority` 走 `fetchpriority="high"` |
| `<VehicleCard>` | 车辆卡片，信息层级固定：图 → 车型年款 → 价格 → 次要参数 → 标签 |
| `<Tag>` | 认证 / 新到 / 降价等标签 |

**页面里禁止出现裸 `<img>`。** 图片不锁宽高比会造成布局抖动（CLS），这是硬性要求。

## 样式写法约束

- **单个元素的 Tailwind 类超过约 8 个，就抽成组件或用 `@apply` 收进语义类。** 禁止把二三十个类堆在一个 div 上
- 禁止内联 `style={{}}`（动态计算值除外，且需注释说明为何无法用类）
- 禁止新增独立 `.css` 文件（`index.css` 除外）
- 重复出现两次以上的结构必须抽组件，禁止复制粘贴

## 页面模式

- **列表页**：筛选（品牌 / 价格区间 / 里程 / 年份 / 能源）+ 排序 + 卡片网格。筛选状态要能反映到 URL query。卡片封面锁 4:3。**375px：左图右文紧凑卡**；**≥720px：两列竖卡**（ADR-117 / ADR-118）。禁止整宽大图占满一屏。
- **详情页**：左图库（主图 + 缩略图条 + 点击开灯箱，支持键盘左右和移动端滑动）/ 右信息栏（车型、大价格、关键参数、标签、询价表单），下方接两列参数规格表
- **响应式断点**：移动端优先书写，向上用 `sm: md: lg:` 递进，禁止只写桌面版再往回压

## 完成定义（本目录追加）

- 每页有 `<title>`，站点有 favicon
- 所有图片有 `alt`
- 列表 / 详情具备加载骨架、空态、错误态
- 列表卡片：手机横向紧凑、平板两列竖卡；封面 4:3；不得出现「只有图没有车型/价格」；375px 一屏能扫多辆
- 手机（375px）/ 平板 / 桌面三档下布局不破、无横向滚动
- 焦点样式可见，表单 label 与控件正确关联
- 首屏无明显布局抖动
